# RailSpotting branding

Everything about how RailSpotting looks and sounds, in one place.

> This folder is a copy of `branding/` from the RailSpotting headend repository, which is the
> source of truth (copied from commit `bdb1918`). Don't edit it here: change it in the headend
> repository and copy it over again. Mentions of "the site" and its CSS describe the headend's
> web pages; the receiver's dashboard and the macOS app use the same colors, mark and voice.

- [brand-guide.md](brand-guide.md): name, the mark, color, type, components, voice and the words
  we use.
- [logo-kit.md](logo-kit.md): every logo file, what it is for, and how the site uses it.
- [logos/](logos/): the logo files (SVG masters, with rendered PNG and ICO files in `logos/png/`).
