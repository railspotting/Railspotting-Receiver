# Security

Please report security problems privately, not in a public issue: use **Report a vulnerability**
on this repository's Security tab (GitHub private vulnerability reporting).

Useful to include: what is affected (the receiver, the macOS app, the status page, or how the
receiver talks to the RailSpotting service), how to reproduce it, and what an attacker could do.
You'll get an answer within a few days.

In scope: the code in this repository, including request signing and the device key, device
linking, the local status page and its token, USB and scanner handling, and the installers. The
RailSpotting service (railspotting.com) is not open source; problems found there are welcome
through the same channel.

Please don't test against other people's receivers or accounts.
